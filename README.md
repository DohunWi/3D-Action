# 🌑 Lucid Knight (Project: Somnia)

> **"꿈을 자각하는 자만이 악몽을 베어낼 수 있다."**
>
> 꿈과 현실의 경계가 무너진 왕국 **'솜니아(Somnia)'**를 배경으로 하는 소울라이크 액션 RPG입니다.
> 플레이어는 유일하게 꿈을 자각한 '루시드 나이트'가 되어, 붕괴해가는 자아를 유지하며 악몽의 근원을 파헤쳐야 합니다.
### 1. "깨어나지 않는 왕국, 솜니아(Somnia)"

> "왕이 잠들자, 태양도 함께 눈을 감았다. 그날 이후 왕국은 영원한 악몽(Nightmare) 속에 갇혀버렸다."
> 
- **왕국 이름:** 솜니아 (Somnia) - 꿈과 잠의 왕국.
- **사건:** **"대수면 (The Great Slumber)"**.
    - 선대 왕이 백성들의 고통을 없애기 위해 '영원히 행복한 꿈'을 꾸게 하는 마법을 시도했으나, 미지의 존재(악신)가 개입하여 꿈이 **악몽**으로 변질되었습니다.
    - 왕국의 모든 물리 법칙이 몽환적이고 기괴하게 뒤틀려 있습니다. (중력이 이상하거나, 건물이 떠다니거나)
- **현재 상태:** 현실과 꿈의 경계가 무너졌습니다. 주민들은 잠든 채로 영혼만 떠돌거나, 악몽에 잡아먹혀 괴물이 되었습니다.

### 2. 주인공(플레이어): "자각몽의 기사 (The Lucid Knight)"

> "이 미친 세상에서 유일하게 '이것이 꿈임'을 자각하고 있는 존재."
> 
- **정체:** 왕실 근위대장이었을 수도 있고, 이방인일 수도 있습니다. 중요한 건 **"높은 정신력(Sanity)"** 덕분에 악몽에 동화되지 않고 **자아(Ego)**를 유지한다는 점입니다.
- **목표:** 왕궁 가장 깊은 곳, **"악몽의 근원(왕의 침실)"**에 도달하여 왕을 깨우고 태양을 되찾는 것.


## 🧠 Worldview & System Design (세계관과 시스템)

이 프로젝트는 게임의 핵심 테마인 **'꿈, 무의식, 자아'**의 개념을 코드와 시스템에 직접적으로 반영하여 설계되었습니다.
물리적인 육체가 아닌 정신체로서의 전투를 표현하기 위해, 전통적인 RPG 스탯을 심리적 용어로 재해석했습니다.

### 1. Core Stats (핵심 자원)

| 인게임 용어 (Lore) | 코드 변수명 (Variable) | 기존 RPG 역할 | 설명 |
| :--- | :--- | :--- | :--- |
| **Ego (자아)** | `currentEgo` | **HP** | 존재의 견고함. 0이 되면 자아가 붕괴되어 사망(Game Over). |
| **Lucidity (각성)** | `currentLucidity` | **MP** | 꿈을 자각하는 정도. 스킬 사용 시 소모되는 정신적 에너지. |
| **Volition (의지)** | `currentVolition` | **Stamina** | 세계에 간섭하려는 의지. 공격 및 회피 시 소모. |
| **Memory Fragments(파편)** | `currentShards` | **Gold/Soul** | 적에게서 회수한 기억의 조각. 자아 강화(Level Up)에 사용. |

### 2. Growth System (성장 시스템)

단순한 신체 단련이 아닌, 정신적 덕목을 쌓아 자아를 강화하는 방식을 채택했습니다.

* **Sanity (정신력)**
    * 역할: **Max Ego (최대 체력)** 증가
    * 설정: 광기와 공포에 저항하며 자아의 그릇을 넓힘.
* **Tenacity (집념)**
    * 역할: **Max Volition (최대 스태미나)** 증가
    * 설정: 꺾이지 않는 마음으로 행동의 원동력을 유지.
* **Awareness (자각)**
    * 역할: **Max Lucidity (최대 마나)** 증가
    * 설정: 세계의 왜곡을 인지하여 더 많은 정신 에너지를 다룸.
* **Conviction (신념)**
    * 역할: **중량 무기** 공격력 보정
    * 설정: "나의 공격은 무겁다"는 믿음으로 타격의 실재성을 강화.
* **Insight (통찰)**
    * 역할: **공격 속도** 및 **이동 속도** 증가
    * 설정: 적의 본질과 패턴을 꿰뚫어 보아 불필요한 움직임을 최소화.

## 🛠️ Technical Stack & Features

* **Engine:** Unity 6
* **Language:** C#
* **Architecture:**
    * **State Pattern:** `PlayerState` (Locomotion, Attack, Interact 등)를 통한 상태 관리.
    * **Singleton Manager:** `GameManager`를 통한 데이터 지속성(Persistence) 관리.
    * **ScriptableObject:** 무기(`WeaponData`) 및 스킬 데이터 관리.
* **Key Features:**
    * **Death Loop:** 사망 시 보유 재화(Shards) 소실 및 유실물(Lost Memory) 생성 시스템.
    * **Hybrid Looting:** 자동 흡수(재화/경험치)와 상호작용 습득(아이템)이 결합된 루팅 시스템.
    * **Ghost HUD:** 슬라이더 기반의 잔상 효과(Ghost Effect) UI.
